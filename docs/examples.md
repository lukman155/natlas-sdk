# Examples

See the `examples/` directory in the repository for full scripts:

- `basic_chat.py`: Simple English chat
- `hausa_chat.py`: Chat in Hausa
- `yoruba_chat.py`: Chat in Yoruba
- `igbo_chat.py`: Chat in Igbo
- `transcribe_audio.py`: ASR example
- `voice_pipeline.py`: Full ASR + Chat pipeline
